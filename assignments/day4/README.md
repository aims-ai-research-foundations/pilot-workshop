## About

Trace one Hausa-English example through one full **LoRA** (low-rank adaptation)
update by hand, then bump the rank from 1 to 2 and see what changes. NumPy only —
no real model, no GPU — so the whole notebook runs in seconds and the time goes
into the **Predict → Run → Explain** protocol rather than waiting on compute.
About 60 minutes.

## How to work through it

- Click **Open in Colab** above to launch the notebook.
- For every code cell, predict the shapes and numbers before running, then
  explain any surprises.
