# Lectures

Lecture materials organised by day. Each day folder contains:

- Demo notebook used during the lecture (with Open in Colab badge)
- `ai-activities/` — AI activities for the day.
- `ri-activities/` — RI activities for the day.

**Slides** live on Google Drive, where facilitators co-edit them, and are linked from the [website Resources page](https://aims-ai-research-foundations.github.io/pilot-workshop/resources/). They are not committed here, so the repo stays light and diffable.
